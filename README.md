# AI Developer Tools Comparison

## Project Overview
This project compares five AI developer tools through a practical Python coding experiment.

## Tools Compared
- ChatGPT
- Google Gemini
- Claude
- Microsoft Copilot
- DeepSeek

## Experiment
A Student Marks Analyzer program was developed using the same prompt in all five AI tools.

## Features
- Average marks calculation
- Highest and lowest marks
- Pass and fail count
- Grade assignment
- Input validation
- Empty-list handling

## Technologies Used
- Python
- Google Colab
- AI developer tools
## Results

The generated programs were tested using the same sample input.
The outputs, code quality, error handling, and explanations
were compared across all five AI tools.
